# ORIGIN Human Baseline — 程浠

Status: `HUMAN_BASELINE / CANDIDATE`
Authority: benchmark only; not Canon, not Route Truth, not Forge seed.

## One spine

2036事故后，程砚为了寻找救回林岚的方法，保存并使用林岚的生物数据进行研究。一次实验意外制造出一个具有林岚基因、却没有林岚记忆与人格的小女孩。程砚没有把她当作“失败的林岚复活”，而是作为独立的人养大，并给她取名程浠。

程浠在事故后的真实人生中与程砚形成父女关系。更远未来，她理解程砚准备利用成熟时间技术回到2036，试图救林岚、救周启明并尽可能修复03:17。她判断这个“全救计划”会毁掉或抹去导致自己诞生、被程砚养大以及父女共同生活成立的因果历史，也可能再次毁掉程砚。

程浠因此主动反对父亲，并最终介入2036，成为本Route的NULL。她不是被简单洗白的伪反派：她确实破坏程砚的全救计划，阻止对周启明的救援，并在事故链中开枪击伤林岚左臂/肩臂区域。年轻程砚因此有充分理由憎恨NULL；更远未来才发现，那个毁掉自己救援的人正是后来真实爱过、养大的女儿。

## Core value conflict

程砚认为自己在救回被夺走的人生；程浠认为父亲正在把悲剧之后真实存在的人生当成应该删除的错误。

父女双方都从真实的爱出发，因此在时间旅行的最终目标上成为敌对双方。

## Known baseline commitments

- 程浠是在03:17之后的研究中出现的新生命，不是2036事故前已经存在的孩子。
- 她具有林岚的生物学来源/基因关联，但没有林岚的记忆与人格；她是独立主体。
- 程砚与程浠在事故后的共同生活中形成真实父女关系。
- 成年后的程浠理解并主动反对程砚的全救计划。
- 程浠在ORIGIN中成为NULL，并真实执行会伤害程砚目标的行动，而不是事后被全部洗白。
- NULL行为至少包括：阻止救周启明、开枪击伤林岚左臂/肩臂区域、破坏全救计划。

## Deliberately unresolved

- 程浠具体在事故后何时被制造、2054时年龄以及何时成年。
- 产生程浠的具体实验机制与最低必要规则。
- 成熟阿尔戈/时间介入的具体机制。
- 程砚“全救计划”的精确操作与为什么它会威胁事故后人生。
- 周启明在ORIGIN中的完整动机、行动链与结局。
- 林岚在ORIGIN中的完整主动作用与她如何理解程浠。
- NULL每一步具体动作的必要性、顺序与对事故的完整因果影响。
- 03:17事故的完整Route-local因果链。

## Benchmark rule

与AI候选比较时，先比较核心Story Engine的清晰度、人物/科幻/03:17融合度、NULL重新解释力和价值冲突强度；以上未解决项属于开发债，不应仅因当前细节更少而自动判输。任何候选若要击败本Baseline，应在核心价值上明显更强，而不只是更完整或术语更多。
