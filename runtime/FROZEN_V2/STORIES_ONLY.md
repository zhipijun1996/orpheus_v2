# 五线共用的Ch2候选正文

03:17，监控曲线突然偏离了原来的轨迹，警报随即响起。程砚抬头，看见通道里一个黑色人影。

“老师还在里面！”他冲向入口，黑影横臂挡住了他。他试图挣开，那人抓住他的衣领，将他拖到矮墙后。沉重的东西砸在刚才的位置，扬起的尘雾遮住了通道。

程砚再次爬起来，双腿却软了。林岚接住他。他攥着她的衣袖，声音终于断成哭声。

“看着我，先呼吸。”她等他的手慢慢松开，将他扶稳，“我去试一下。”

林岚走到侧面的操作台前。警报灯一闪一闪，她伸手握住手柄。她抬眼看见通道那端的黑色人影举起了枪。

她想转身躲开，左肩却猛地一痛，手从柄上滑下来。

程砚听见枪响，抬头看见林岚捂着肩膀，血从指间渗出。他喊她的名字，爆炸的白光却先一步吞没了视野。


# FLESH

林岚醒来时，左肩还在流血。

“别动，先止血。”

她抓住那人的袖口：“程砚呢？”

“我在。”

声音老了。她抬头，看见熟悉的脸上多出的皱纹，又看见墙上的日期：2054年。

她以为爆炸把自己掀进了隔壁。他却说，这是十八年后的接收室。她低头看着伤口，忽然不敢再碰他。

程砚这些年留下的东西占满两间屋子：调查卷宗，失败的阿尔戈报告，还有程浠七岁时画的画。画上写着“爸爸今天没有迟到”。

“那天其实迟到了。”程浠说，“他又去找NULL的线索。我等到礼堂关灯。”

后来父亲设了两个接送闹钟。有一年他关掉实验，陪她看完演出。她记得这些，和那间黑下来的礼堂一样清楚。

晚饭时，林岚照旧伸手拿程砚的杯子。他按住杯沿：“里面是药。”

她收回手。他们安静地吃完了饭。

成熟的阿尔戈已经送回过完整活体，事故残留也与回返装置吻合。程砚准备回去接她和周启明。

林岚看见黑色防护服：“你还没出发，我肩上已经有了你的子弹。”

他把侧台线路图铺开。那根手柄启动隔离，也会焚毁尚未撤空的核心。

“这是你开枪的理由？”

“我得先进去看见。”

“那就记住，我当时也在救人。”

她接管了接收端。出发前，四个传送环逐一测试：给她的，给老师的，备用救伤员的，还有他自己的。程浠亲手将最后一个扣在父亲腕上。

“你也在撤离名单里。”

“我会回来。”

回到03:17，程砚横臂挡住年轻的自己。青年拼命挣扎，他只能抓住衣领，将人拖到矮墙后。坠物砸下，尘雾灌满通道。

隔着尘灰，他看见林岚接住那个哭泣的人。再抬头，她已经走向侧台。

核心里，周启明正在拆卸压住检修员的支架。程砚向侧台奔去，倒下的管道横在脚前。他喊她停手，声音被警报吞没。她握住手柄，抬头，看见他举枪。

他朝她左肩开了枪。

她的手滑下来。他翻过管道，在爆炸扬起的烟尘里给她扣上传送环，按下启动键。她消失时，年轻的自己已经倒在矮墙旁。

周启明拖着检修员爬出核心，支架再次下沉，卡住了老师的腿。程砚钻进下面，用背顶起斜梁。多出的这具身体终于占住了一个原本没有人能站的位置。

他把两个救援环推过去。周启明先替昏迷的检修员扣好，又摸索着扣上自己的。

“你是谁？”

程砚抬起脸。

老师认出了那道旧疤，手停了一下：“你怎么熬成这样。”

程砚险些卸了力。

支架的焊口正在撕裂。周启明撑住地面：“放下来，再找位置。这样你来不及。”

一放，梁就会重新压住他的腿。程砚不知道还能不能抬起第二次。

“先走。我还有一个。”

老师看着他腕上的环，终于按下两人的启动键。

重量骤然偏移。程砚伸手去按自己的按钮，支架却先折了下来。

接收室落下两个人。林岚继续呼叫，直到通道里只剩坍塌声。

后来她把枪击经过写进事故记录，没有删去开枪者的名字。

“他救了我。”她对程浠说，“可我仍然恨那一枪。”

程浠把父亲的返程方案折好：“他也答应过我。”

她没有哭，也没有替他解释。

第二天，她们一起回家。接送闹钟响了。程浠关掉一个，另一个响起来时，她把脸埋进林岚没有受伤的肩窝。

# ECHO

林岚醒来时还护着左肩：“等一下，我能把手柄拉到底。”

肩上没有伤。窗外的楼群陌生，床边程砚的头发白了一半。她抓住他袖口，先问老师在哪儿，才问现在几点。

“2054年。”

她慢慢松手。他等了十八年，她却还没有从那声枪响里出来。

程砚给她看研究本。早期实验里，没有同DNA宿主的接收端确实长出了新身体；他据此相信阿尔戈能送自己回去救人。同DNA宿主会怎样，还没人验证。

夹页掉出一张画：爸爸、浠浠，一个被涂掉的无脸人。

程浠来自林岚生物数据的实验。女孩小时候打翻培养液，程砚曾叫错名字；看见她赤脚站着，他跪下擦鞋，改口问浠浠疼不疼。后来他学会先陪女儿过生日，再回实验室找失踪的人。

林岚把画还给他：“她是你的女儿。我也不是你等来的奖赏。”

她搬进客房，要求看完记录再决定是否帮助回返。程砚答应了，却在看到中枪画面后独自启动阿尔戈。她追到机房，只摸到尚热的扶手。

记录没有随他离开。她坐下来，从头播放。

他落进年轻的身体，认出自己十八年前咬破的指甲。所谓独立身体没有出现。被活埋般的恐惧击穿主控，年轻程砚看见曲线偏离、警报亮起；未来的他只能在后台跟着看，无法开口。

另一具身体属于林岚。2072年的程浠回来找父亲：他在2054年走后，是林岚陪她长大，教她修灯，最后在病床上说，别把等待过成一生。葬礼之后，她仍走进了机器。

她在侧廊取得初始控制，拉起林岚防护服的黑色兜帽，合下面罩，赶到入口。年轻父亲撞进她怀里，她把他拖过矮墙，吊架随即砸下。

他哭着找林岚。她突然害怕：自己正把养大她的人关在身体里。

尘雾遮住两侧视线。她蹲在墙后掀掉兜帽、面罩，听见父亲抽噎，羞愧终于冲散控制。林岚恢复感知时眼前只有跪倒的程砚；她伸手接住他。程砚看见的是熟悉的脸，没有看见黑影卸下面罩。

林岚走向操作台。年轻程砚发现顶上的火正沿电缆逼近她，扑向墙边泄压杆，扳到底；火流折向空槽，给她和核心里的周启明争出片刻。他还想喊她快走，后台的未来程砚却认出了她握住的红柄：断电，也会清空扫描。

又一次失去她的恐惧夺走行动权。他蹲在矮墙后套起同款黑罩，从应急柜取枪，起身瞄准。林岚只能看见逆光中的遮面人形；程砚的脸和辨认身份的动作，都藏在她视线之外。

枪响。未来程砚缩回墙后，枪脱手滚入排水沟。他掀开兜帽与面罩，想吐。自己竟然向她开了枪。这个念头击垮主控。

年轻程砚只听见通道里尚未散尽的枪声，空着手抬头，看见林岚的血；白光扑来。他没有经历举枪，更没有看见谁在黑罩里面。

爆炸掀倒林岚。疼痛与濒死惊惧让程浠再次抢到控制；她爬向发送键，却在碎玻璃里看见林岚的脸。那不是她可以拿来抵债的身体。她忍着恐惧退下，把最后几秒还给宿主。

周启明为延长这几秒拆下门锁电池，放弃自己的开门机会，接住扫描器：“送得走中枪时那份。现在的你，走不了。”

林岚终于明白，醒来的那个人不会替她死。她仍按下发送：“让她醒。别说她欠谁。”

2054年的林岚关掉记录，把违约、占用宿主和枪击的原始日志交给事故调查，要求停用阿尔戈；她撤回合作，也搬离程砚的家。每次警报响，她仍先护住没有伤疤的左肩。

程浠问能否去看她。

“可以。”林岚递给她新地址，“这是我答应你的。”

# ORIGIN

林岚醒来时，核心门还在眼前。她伸手去按急停，指尖穿过了红灯。

程砚关掉投影。玻璃映出她肩上的绷带，也映出他的白发。

“2054年。”他说。

她握住他的手，找到食指上切水果留下的疤，才开始发抖。床边一个女孩抱紧了水杯。

十八年里，程砚翻过废墟，卖掉住房，从匿名样本匣中取得林岚的组织与神经记录。2047年的培养事故产生了一个没有她记忆的新生命。程砚签下监护文件，学会冲奶，在实验记录背面列退烧时间；后来另买了一本册子，只写女儿的事。

“这是程浠。”他对林岚说，“我女儿。”

林岚来自2036。伤处的定位片和接收记录表明，有人在爆炸中把她送到了这里。周启明没能回来。

程浠最初不肯单独跟她待着。有天林岚翻看相册，女孩突然问：“你回来了，爸爸还要我吗？”

林岚把相册还给她：“这得让他亲口告诉你。我想知道，你愿不愿意明天带我去学校。”

此后十四年，林岚学会给她编不勒头皮的辫子，陪她等补考结果。程浠第一次失恋，把门反锁，林岚在门外坐到天亮。她也会因程浠偷改实验记录，禁止她进实验室。和好时，程浠把检讨塞进她的外套，下面压着一句：你还来接我吗？

2068年，他们终于查明，周启明当时在手动泄压，为楼下撤离争取时间。程砚备好了接替设备，要回去救他和林岚。

程浠却读到父亲的旧笔记：“若能全救，终止奥菲斯。”通往她出生的每一次培养，都起于失去林岚。

她要求先留下全部样本和培养步骤。父亲答应保存，却不能答应照着事故再造一个孩子。

“那我会怎样？”

“没人知道回去意味着什么。我不会把你当成可以删掉的一段。”

她追问，直到他也不再有话。夜里，她取下出发设备的接触器，打算拖到两人放弃。父亲换好备用件，把拆下的零件放在餐桌上。旁边仍是留给她的晚饭。

她看着那碗饭，第一次觉得自己的家可能已经只剩在自己记忆里。没有证据证明这一点；可她拿走了另一套设备，提前进入2036。

黑色面罩里，她看见年轻父亲冲向入口。她挡住他，抓住衣领拖到矮墙后，听见重物落下。他哭着喊老师。小时候她发烧，他也是这样一遍遍叫她。

林岚扶稳他，走向侧台。程浠认出母亲的习惯：先安慰别人，再去做危险的事。

那只手柄能打开检修通路，让接替设备送进核心。程浠已从背面锁住电控，想使林岚放弃；林岚仍握住了机械手柄。

她可以现身，可以求她停下。面罩里的呼吸越来越急。她举枪，扣下扳机。

趁爆炸前的混乱，她采集伤处组织，封存扫描记录，把样本匣藏进检修柜，再将定位片贴入伤口，启动通往2054的转移。她按住林岚的肩，听见她疼得吸气，像从前替自己消毒时那样。

白发的父亲赶到，接替缆已经送入核心。周启明看见他，没有追问，只喊：“下面还没走完，接住！”

程浠攥住割刀。父亲说：“让我接。他还能出来。”

她看着他伸手，割断了缆。

门内，周启明重新压住阀门，仍等着外面的人。门合上时，程浠没有再说自己没办法。

回程后，林岚问：“我在门外陪过你那么多晚，你为什么不肯再叫我一次？”

程浠低着头：“我怕你会选他。”

程砚交出了全部记录和女儿的供述。第一次探视，他带了她惯用的胃药，隔着玻璃询问能否转交。程浠叫爸爸，他应了一声，手却始终没有贴上玻璃。

# BLINDSPOT

林岚醒来时，左手还在找那个柄，摸到的却是床栏。她催人去救老师。床边的程砚抬起脸，眼角已经有了皱纹。窗外，实验楼旧址长满树木。

“十八年。”他说。

她没接那杯水：“你先让我看看日期。”

程砚给她看事故档案，也给她看这些年的照片：拆开的录音机，七岁程浠画的全家福，发烧的小女孩攥着他的袖口。十八岁的程浠站在门边，没有叫她妈妈。

回家那晚，林岚选了客房。程砚把两把旧牙刷并排摆好，又收起一把。

阿尔戈只能接通尚未被可靠确定的历史过程。林岚左肩的弹道、程砚昏厥前所见，都是必须满足的事实；她如何离开现场，却没有记录。现在她活着，但送她来的人尚未出发。

程砚仍想先让枪击不发生。第一次有限干预，他向事故前的备用频道送去停机警告；回传中，年轻的自己弯腰查找杂音，错过按钮。他认出了当年那声干扰。第二次，林岚遥控维护臂，试图提前完成侧台操作；卡住的连杆折断，触发隔离。档案里那次“原因不明的短路”，有了来处。

她摘下接口：“我们一直在替已经发生的事补原因。”

程浠翻出周启明的死亡证明：批量填报，没有遗体。检修井录像在事故前已经中断。周最后被看见还在核心，此后没人能证明他在哪里。

他们把井道图铺满餐桌。侧台手柄控制应急泄压，蒸汽出口就在井内。林岚终于知道自己那一下可能做了什么，却仍问：“所以你准备朝我开枪？”

程砚答不出来。

完整回返前，程浠参加返回端演练。伤员若不能逐个通过，必须抽出限流销，撑开双人通道；抽销后，门板会立即向内合拢，操作者只能从红线外用长杆支撑。演练中长杆被折叠担架卡过一次。他们改用软兜，留下警示。

程砚穿黑色防护服返回03:17。他横臂挡住年轻的自己，抓住衣领拖到矮墙后。顶上的配重块砸落，把他的解释淹没了。林岚安抚完那个年轻人，握住手柄。他隔着尘雾奔过去，来不及夺下，只能举枪。

她中弹倒下。他直到白光之后才敢扶她，按预定坐标把她送到十八年后的病床。那不是一次重来；她肩上的伤一直出自他的手。

周启明正在核心拆日志盒。他曾签字批准带异常运行，现在不肯留下原始记录。程砚说出井道出口，周终于抱着盒子跟他走。

到返回口，周被落物割伤的腿撑不住了。程砚用软兜拖他；周护在胸前的日志盒挂住兜绳，横卡在门槛。程浠的长杆够不到卡点。她抽销，越过红线拨开盒子，让父亲把老师拖出来。门板夹住她的右手。

医院里，周说：“还有两个人没找到。下次我进去。”

林岚指着他的日志：“你先解释为什么没有停机。”

周说公开调查可能封死救人的空白。她翻到未解码的检修终端目录：“这里可能存着最后的刷卡记录。查出来，才会知道谁到过井口。公开本身会怎样，你没有证据。”

他摸着盒角上的血，承认：“我想救人，也怕他们只记得那张批准单。”

程浠说：“手是我伸的。别替我后悔，也别替我说值得。”

程砚取消下一次载人回返，继续改造伤员通道。程浠要求参与验收：“先证明不用谁伸手进去。”

林岚坚持先公开已有日志，自己的证词由自己写。周签了名，却保留异议：“如果查到有人还来得及救，我仍会申请回去。”她答：“那就把谁要承担风险也写进去。”

她搬走时带走了一把旧牙刷。

# NOBODY

林岚醒来，右手还悬在半空。她伸向眼前的手柄，指尖却穿了过去。肩膀没有痛，警报声也在她转头时戛然而止。

“避难间呢？”

墙壁退成网格。屏幕外，一个头发花白的人扶住桌沿。

“现在是2054年。”

她认出程砚，先笑了一下，等他跟着笑。他没有。

实验期间留在本地设备里的意识记录，止于中枪后的几秒。阿尔戈刚刚完成修复。她的身体已经死去十八年。

“那我刚才救到人了吗？”

程砚把七个名字调出来。她逐个看完，才问他为什么变成了这样。

十八年里，他研究阿尔戈，追查那个黑衣人。墙上另有一排铅笔刻度：程浠七岁、八岁、九岁。女儿曾站在实验室门外，捧着化了一半的生日蛋糕，等父亲看完一段反复播放的录像。

这次她没有等。

“许诚又来信了。”她把信放到父亲手边，“你至少读完。”

许诚从事故后的询问开始，就承认挡路和拖拽都是自己做的。他说自己看见上方构件断裂，才拦住程砚。程砚当年去病房追问过他，也相信那一下救了自己的命；但许诚解释不了另一处枪声，更不知道黑衣人是谁。程砚后来认定，他只是受人指使的现场帮手。

七名幸存者一直讲述林岚开启排热、许诚接应他们的经过。他们被困在门后，没有看见枪手。他们纠正过报道里“无人获救”的说法，却没有证据回答程砚最执拗的那个问题：谁让林岚死在这里？

“我不是没听他们说。”程砚说。

程浠回答：“可你总把他们说完以后解释不了的地方，当成你说对了。”

林岚要求见许诚。

他已经不能久站，却仍认出她抬手的习惯。她问起手柄后面的管路，他从纸上画出避难间和低温阵列：排热能够救人，也会毁掉志愿者的意识记录。

程砚替导师辩解：“他答应过那些人。”

他们随后读到周启明留下的工作记录。最早是替临终志愿者申请延长保存；后来，他拒绝一次会损失记录的停机检修，亲自守了通宵。林岚记得那晚给他送过饭，还劝程砚别催老师。

再后来，他签下了优先保全阵列的应急指令。

程砚把那页翻回去，第一次没有替签名找理由。

他们依据修复的记录重建03:17。

许诚穿上救援服，离线终端显示NULL。他横臂挡住程砚，抓住衣领，把人拖到矮墙后。吊架坠下时，他的左手仍扣在衣领上。程砚要求暂停，摸了摸自己的后颈。

“是他。”他说。这次没有再补一句“但幕后还有人”。

画面继续。林岚走到操作台，通道那端的人举枪。逆光和面罩遮住了脸；当时的她只来得及躲。

枪响后，记录里留下了一句迟来的声音。

“岚岚，别再动了。我还可以转存。”

周启明。

林岚认得这个称呼。许多年前，她第一次做坏实验，也是他这样叫她，替她收拾满地玻璃。她没有立刻说话。

重建中的她用右手重新够住手柄，将身体压上去。许诚收到阵列保护指令，却听见避难间里有人拍门。他拔掉耳机，转身接人。

七个人从热雾里出来。周启明退回核心，保住了一小片存储区，也留下了林岚的记录。

程砚关掉重建，几天没有启动阿尔戈。第五天，他回来，向林岚念调查报告。念到“为挽救研究不得已开枪”，停住了。

“我以前以为，只要找到另一个凶手，就还能记得他给我们留饭。”

“你可以记得。”她说，“可别替中枪的我说，她愿意。”

他删去“不得已”，保留了导师救下记录的事实，也写下枪是谁开的。

程浠补过生日那晚，林岚在屏幕里提醒他把袖口离蜡烛远些。他移开手，忽然问她明天想看哪里。

“先让我自己选。”她说。

他把地图转向了她。
