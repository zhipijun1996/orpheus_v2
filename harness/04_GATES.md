# Gates

## Story Gate
**Human Motive:** understandable desire; sufficient knowledge; reversals earned by experience; character remains an agent.

**Drama Proof:** explicit desire/incompatibility; protagonist action changes the situation; 2+ signature scenes; ending changes relationship/life/durable commitment; Logic Scout is not `DEAD`.

## Reveal Gate
Working Truth is credible/actionable; Deep Truth creates meaningful Reveal Delta; evidence is fair; a concrete scene carries the reveal; no failed motive props it up.

## Prototype Gate
6–12 beats form one causal story; action is legible without technical exposition; Cold Reader finds a strong hook; Drama cites scene evidence.

## Integration Gate
Active Routes have current Interfaces; shared facts satisfy required inputs; required-open facts remain open; collisions are resolved/deferred/escalated; shared additions serve cross-route function.

## Closure Gate
`PLAUSIBLE -> SOLVABLE -> PROVEN`

## Human Gate
Human Pack: 1–3 candidates, one spine each, key difference, largest risk, strongest objection, one decision.
