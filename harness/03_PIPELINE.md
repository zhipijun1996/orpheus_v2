# Creative Pipeline

## EXPLORE
Diverge at one scale: `DRAMA / REVEAL / MECHANISM / SCENE / ROUTE / ARCHITECTURE`.
Deliver 6–10 structurally different short candidates; use 2–3 Forge workers when divergence matters.

## BUILD
Develop 1–3 candidates with:
- one-sentence Story Spine
- 6–12 beats
- 2 signature scenes
- Working / Deep Truth when relevant
- largest risk

Freeze candidates before Review.

## REVIEW
Applicable reviewers inspect the same frozen artifact independently and may run in parallel. They identify; repair belongs to a later Task.

- **Cold Reader:** continuation pull, boredom/repetition, unbelievable action, understandable cruelty, author-forced reasoning.
- **Drama:** desire, opposition, action/counteraction, irreversible change, motive continuity.
- **Mystery:** Working Truth, evidence, Reveal Delta, fairness.
- **Consequence:** when later judgment depends on a capability, test both failed and successful use; value reversal needs concrete earned experience.
- **Logic Scout:** `CLEAR / RISK / DEAD` with decisive causal blockers.

## SYNTHESIZE
After required reviews freeze, return `SELECT / FUSE / FORK / DROP / ROLLBACK_PARENT`.
Fusion: `DEEPEN / REPLACE / COMPRESS / EXPAND`.
Priority: human plausibility > drama/agency > Route promise > mystery value > novelty.
Do not invent hidden author intent to rescue missing evidence.

## CROSS-ROUTE SYNTHESIS
Use Interfaces to extract required common observations, preserve required uncertainty, open collision tickets, and derive the smallest viable shared layer.

## Simplifier
Every 2–3 Sprints: `DELETE / MERGE / REPLACE / DOWNGRADE` only.
