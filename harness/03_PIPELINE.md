# Creative Pipeline

## EXPLORE
Diverge at one scale: `DRAMA / REVEAL / MECHANISM / SCENE / ROUTE / ARCHITECTURE`.
Deliver 6–10 structurally different short candidates; use 2–3 Forge workers when divergence matters. Novel mechanisms are not penalized by count during divergence.

## BUILD
Develop 1–3 candidates with: one-sentence Story Spine; 6–12 beats; 2 signature scenes; Working / Deep Truth when relevant; largest risk.
For mechanism-heavy work, classify new rules as `ENGINE / SUPPORT / PATCH`; state each ENGINE in plain language and identify any earlier observable trace required by a later reveal.
Freeze candidates before Review.

## REVIEW
Independent reviewers inspect the same frozen artifact; they identify, not repair.
- **Cold Reader:** pull, boredom, unbelievable/author-forced action, jargon-driven comprehension failure.
- **Drama:** desire, opposition, action/counteraction, consequence, motive continuity; mechanism should create choices rather than merely demonstrate a system.
- **Mystery:** Working Truth, evidence, Reveal Delta, fairness; decisive mechanism properties need prior observable evidence when the project requires it.
- **Consequence:** test failed and successful capability use; value reversal needs earned experience.
- **Logic Scout:** `CLEAR / RISK / DEAD`; trace causal blockers and PATCH chains.

## SYNTHESIZE
After reviews freeze: `SELECT / FUSE / FORK / DROP / ROLLBACK_PARENT`; fusion: `DEEPEN / REPLACE / COMPRESS / EXPAND`.
Priority: human plausibility > drama/agency > Route promise > mystery > novelty. Prefer high narrative leverage and shallow PATCH dependency, not fewer mechanisms by itself. Do not invent hidden rationale to rescue missing evidence.

## CROSS-ROUTE SYNTHESIS
Use Interfaces to extract common observations, preserve required uncertainty, ticket incompatible needs, and derive the smallest viable shared layer.

## Simplifier
Every 2–3 Sprints: `DELETE / MERGE / REPLACE / DOWNGRADE` only.
