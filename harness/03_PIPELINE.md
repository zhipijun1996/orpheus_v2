# Creative Pipeline

## EXPLORE
Diverge at one scale:
`DRAMA / REVEAL / MECHANISM / SCENE / ROUTE / ARCHITECTURE`

Deliver 6–10 short candidates with structural differences.

## BUILD
Develop 1–3 candidates.

Minimum:
- one-sentence Story Spine
- 6–12 beats
- 2 signature scenes
- Working Truth when relevant
- Deep Truth when relevant
- largest current risk

## REVIEW

### Cold Reader
Identify:
- strongest continuation pull
- boredom or repetition
- unbelievable action
- understandable cruelty
- author-forced reasoning

### Drama
Cite scene evidence for:
- desire
- opposition
- action / counteraction
- irreversible relational or life change
- continuity of motive across major reversals

### Mystery
Check:
- Working Truth
- supporting evidence
- Reveal Delta
- fairness

### Consequence check
When later character judgment depends on using a capability, examine the consequences of both failure and successful use.
A value reversal must cite the concrete experience that earned it.

### Logic Scout
Return `CLEAR / RISK / DEAD`.
Identify only; repair belongs to a later Task.

## SYNTHESIZE
Legal results:
`SELECT / FUSE / FORK / DROP / ROLLBACK_PARENT`

Fusion modes:
`DEEPEN / REPLACE / COMPRESS / EXPAND`

Synthesis priority:
1. human plausibility
2. drama / agency
3. Route promise
4. mystery value
5. novelty

## CROSS-ROUTE SYNTHESIS
Use Route Interfaces to:
1. extract common required observations
2. preserve explicitly required uncertainty
3. open collision tickets for incompatible needs
4. derive the smallest shared layer that supports active Routes

## Simplifier
Every 2–3 Sprints, run a pass limited to:
`DELETE / MERGE / REPLACE / DOWNGRADE`
